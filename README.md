# .github

이 조직의 **공통 GitHub 설정**을 담는다.

| 파일 | 무엇 |
|---|---|
| `.github/PULL_REQUEST_TEMPLATE.md` | 조직 공통 PR 양식 |

GitHub 은 **자기 템플릿이 없는 저장소**에 이 파일을 자동으로 쓴다.
저장소가 자기 `.github/PULL_REQUEST_TEMPLATE.md` 를 두면 **그쪽이 이긴다.**

> ⚠️ **이 저장소는 public 이어야 동작한다.** GitHub 의 기본 커뮤니티 파일 규칙이다
> (적용 «대상» 저장소는 private 이어도 된다 — 이 저장소만 public 이면 된다).
> private 으로 되돌리면 템플릿은 **조용히 아무 일도 안 한다.**
